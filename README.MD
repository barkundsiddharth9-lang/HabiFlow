# 🚀 HabiFlow

HabiFlow is a habit tracking web application designed to help users build positive habits, monitor daily progress, and stay consistent with their goals.

## ✨ Features

- 📅 Daily habit tracking
- 📊 Progress monitoring
- 🔐 User authentication
- 🎯 Habit completion statistics
- 💻 Clean and responsive UI

## 🛠️ Tech Stack

- Python
- Flask
- HTML
- CSS
- JavaScript

## 📂 Project Structure

```
HabiFlow/
│── app.py
│── requirements.txt
│── templates/
└── README.md
```

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/SiddharthBarkund/HabiFlow.git
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run the application

```bash
python app.py
```
